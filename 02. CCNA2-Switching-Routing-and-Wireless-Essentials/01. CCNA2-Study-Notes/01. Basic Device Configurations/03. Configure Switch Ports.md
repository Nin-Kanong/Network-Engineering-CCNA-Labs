### **1.2.1 Duplex Communication**

There are two types of communication:

| Type            | Easy Explanation                                                                   |
| --------------- | ---------------------------------------------------------------------------------- |
| **Full-Duplex** | Both devices can send and receive data at the same time. No collisions.            |
| **Half-Duplex** | Devices can send or receive data, but not at the same time. Collisions can happen. |

**Example:**

- **Full-Duplex:** Like a phone call. Both people can talk and listen at the same time.
- **Half-Duplex:** Like a walkie-talkie. Only one person can talk at a time.

### Configure Switch Ports at the Physical Layer

We can manually configure a switch port's speed and duplex mode.

- ``duplex full`` = Enable Full-Duplex.
- ``speed 100`` = Set speed to 100 Mbps.


The table shows the commands for **S1**. The same commands can be applied to **S2**:

| Task | IOS Commands |
| :--- | :--- |
| Enter global configuration mode. | `S1# configure terminal` |
| Enter interface configuration mode. | `S1(config)# interface FastEthernet 0/1` |
| Configure the interface duplex. | `S1(config-if)# duplex full` |
| Configure the interface speed. | `S1(config-if)# speed 100` |
| Return to the privileged EXEC mode. | `S1(config-if)# end` |
| Save the running config to the startup config. | `S1# copy running-config startup-config` |
