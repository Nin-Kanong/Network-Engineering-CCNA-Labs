## VLAN definition


<img width="1223" height="712" alt="image" src="https://github.com/user-attachments/assets/eaf75e4d-9910-4d82-af74-8704a82d8bba" />


**VLAN (Virtual LAN)** divides one physical network into multiple logical networks.

Why use VLANs?
- **Security**: Separates departments.
- **Performance**: Reduces broadcast traffic.
- **Management**: Organizes devices into groups.
- **Flexibility**: Devices on different floors can belong to the same VLAN.

Example:
| VLAN   | Department | Purpose                        |
| ------ | ---------- | ------------------------------ |
| VLAN 1 | Default    | Default VLAN on Cisco switches |
| VLAN 2 | IT         | IT department                  |
| VLAN 3 | HR         | HR department                  |
| VLAN 4 | Sales      | Sales department               |

> **Note**: **VLAN 1** exists by default on Cisco switches. 
---


## Types of VLANs

There are **5 common VLAN types**:

| VLAN Type       | Simple Explanation                                          |
| --------------- | ----------------------------------------------------------- |
| Default VLAN    | VLAN 1. All switch ports belong to it by default.           |
| Data VLAN       | Carries normal user traffic, such as computers and laptops. |
| Native VLAN     | Carries untagged traffic on an 802.1Q trunk.                |
| Management VLAN | Used to manage switches remotely, such as SSH or Telnet.    |
| Voice VLAN      | Carries voice traffic from IP phones.                       |

Example:
```
show vlan brief
```

This command displays VLANs and their assigned access ports.

> **Note**: Data = user traffic, Native = untagged trunk traffic, Management = switch administration, Voice = IP phone traffic.
