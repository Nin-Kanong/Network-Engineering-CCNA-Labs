##### Configure the VTY lines for SSH only
````
line vty 0 15
login local
transport input ssh
no password
exit
````
<img width="392" height="122" alt="image" src="https://github.com/user-attachments/assets/00e21025-6e6b-4a82-8ce8-d1839b2bab7c" />


What each command does:
| Command               | Purpose                                                 |
| --------------------- | ------------------------------------------------------- |
| `line vty 0 15`       | Selects the remote-access terminal lines.               |
| `login local`         | Uses the local username database to authenticate users. |
| `transport input ssh` | Allows SSH and disables Telnet on these lines.          |
| `no password`         | Removes the old VTY line password.                      |
| `exit`                | Returns to global configuration mode.                   |




Exit and save the configuration:
````
end
copy running-config startup-config
````
